# AGENTS.md — нейросетевой синтез многоплоскостного ДОЭ

Инструкции для команды из трёх человек и её coding-агентов: декомпозиция, контракты и приёмка. Исходный план: [PIPELINE.md](PIPELINE.md).

## 1. Цель и границы проекта

Получить воспроизводимый конвейер: **4 целевых PNG → один проход обученной сети → одна фазовая маска → восстановление на 4 расстояниях → PNG и метрики**.

План: MVP за 7–9 часов, предел — 24 часа от старта. Время обучения уточнить измерением на доступном компьютере. У каждого участника одновременно одна основная задача.

| Параметр | Зафиксированное значение |
|---|---|
| Вход | 4 одноканальных 8-битных PNG, каждый 128×128 |
| Выход сети | Одна фазовая маска 128×128 |
| Сохраняемая фаза | `[-π, π]`, PNG: `0 → -π`, `255 → +π` |
| Длина волны | `532e-9` м |
| Шаг пикселя SLM | `10e-6` м |
| Расстояния | `[0.0241, 0.0253, 0.0265, 0.0277]` м |
| Распространение | Одно-FFT формула Френеля из задания, один FFT на плоскость |
| Реконструкции | 4 одноканальных 8-битных PNG, каждый 128×128 |
| Метрики | Pearson и SSIM для каждой пары, среднее и худшая плоскость |
| Сдача | Исходники, данные/генератор, checkpoint, изображения, метрики, инструкция |

Цели могут быть четырьмя независимыми изображениями, а не слоями одной сцены. Их точное восстановление одной маской не гарантируется.

**MVP: Zeng (2026) + DeepCGH (2020) + Peng (2020).** От Zeng берём многоплоскостную U-Net, от DeepCGH — обучение по оптическому восстановлению без обязательных эталонных фаз, от Peng — принципы PyTorch-оптики и градиентного baseline. Пропагатор адаптируем к одно-FFT Френелю задания. Уточнение выхода сети — отдельный гибрид; чистую сеть оценивать отдельно.

**Неопределённость кейса:** план использует `abs(U)`, исследование — `abs(U)**2`. В доступной «AI фотоника.pdf» выбор не указан; «Хакатон_задача_q2.pdf» при подготовке файла отсутствовал в рабочей папке.

- Рабочий режим до проверки полного условия: `reconstruction_value = "amplitude"`, то есть `abs(U)`. Это предположение команды.
- Если требуется интенсивность, установить `"intensity"` (`abs(U)**2`) для train, baseline, экспорта и оценки; повторить эксперименты.
- Физику и протокол хранить в `config.py`, снимок конфигурации — в checkpoint и результатах. Несовместимость checkpoint и протокола должна вызывать явную ошибку.
- Сравнивать цели на собственной сетке каждой плоскости: `dx_out = wavelength_m * z_m / (N * slm_pitch_m)`. Для четырёх расстояний это примерно `[10.0166, 10.5153, 11.0141, 11.5128]` мкм.

В T0 записать в README: имена A/B/C, старт/дедлайн, источник условия, режим, нормировку, устройство, версии, seed, выбор checkpoint и предположения.

Целевая структура; файлы и команды ещё предстоит реализовать:


Тензоры PyTorch: `[B, C, H, W]`. Порядок каналов = порядок z. Расстояния в метрах, фаза в радианах. Основное разрешение 128×128; физика также поддерживает маленькую сетку для независимого теста.

```python
load_four_png(paths: list[str]) -> Tensor
# float32 [1, 4, 128, 128], uint8 / 255; порядок paths = порядок z

make_train_loader(batch_size: int, seed: int) -> Iterable[Tensor]
# поток float32 [B, 4, 128, 128]; воспроизводимый RNG, без повторного сброса на каждом batch

model(images: Tensor) -> Tensor
# float32 [B, 4, 128, 128] -> float32 [B, 1, 128, 128], фаза [-π, π]

fresnel_1fft(phase: Tensor, z_m: float) -> Tensor
# float32 [B, 1, H, W] -> complex64 [B, 1, H, W]

propagate_four(phase: Tensor) -> Tensor
# complex64 [B, 4, H, W]

reconstruct_four(phase: Tensor) -> Tensor
# float32 [B, 4, H, W], abs(U) или abs(U)**2; ещё без нормировки

normalize_recons(values: Tensor) -> Tensor
# float32 [B, 4, H, W] -> float32 той же формы, [0, 1]

optimize_phase(targets: Tensor, *, initial_phase: Tensor | None, steps: int, seed: int) -> Tensor
# цели [B, 4, H, W] -> фаза [B, 1, H, W]; None означает случайный старт

export_phase_png(phi: Tensor, path: str) -> None
load_phase_png(path: str) -> Tensor
# одна маска [1, 1, 128, 128]; запись uint8, чтение в радианы

evaluate_four(targets: Tensor, recons: Tensor) -> dict
# одна четвёрка [1, 4, 128, 128]; recons — повторно прочитанные PNG / 255
```

A реализует общую нормировку; B/C импортируют её. Не дублировать физику и нормировку для train/infer. В обучении не отрывать граф градиентов преобразованиями в NumPy/PNG.

**Архитектура MVP:** U-Net ширины 16, совместный вход четырёх глубин, encoder/decoder со skip-связями, выход `π*tanh(raw)` в один канал. Это адаптация Zeng. Space-to-depth/depth-to-space и обучаемый Fourier-блок — после первой версии. Физический FFT вне предсказателя фиксирован, его параметры не обучаются.

Зависимости: Python, PyTorch, NumPy, Pillow, scikit-image, pytest; Matplotlib для коллажа. C фиксирует проверенные версии. Чужой TensorFlow-проект целиком не переносить.

## 5. Физика, нормировка и экспорт

Реализовать формулу из задания:

```text
U0 = exp(i * phi)
Uz = exp(i*k*z)/(i*λ*z) * exp(i*π*(x²+y²)/(λ*z))
     * FFT_centered(U0 * exp(i*π*(u²+v²)/(λ*z))) * dx_in²
k = 2*π/λ
```

Координаты — центрированные, в метрах. Зафиксировать `norm="backward"`, `fftshift/ifftshift`. Вынесенный глобальный фазовый множитель документировать и учитывать одинаково в основном и эталонном расчётах.

У Peng брать работу с комплексными тензорами, autograd и итерационной оптимизацией. Его ASM и калибруемую модель не переносить в оператор проверки. Один и тот же собственный Френель используется в train, baseline и infer.

**Начальная нормировка команды:** независимо для каждого элемента batch и каждой плоскости делить неотрицательную реконструкцию на её собственный максимум:

```text
R = abs(U)                         # либо abs(U)**2 согласно конфигурации
R_norm = R / max(max_over_H_W(R), 1e-8)
T = input_uint8 / 255
loss = mean((R_norm - T)**2)        # по batch, плоскостям и пикселям
```

Схема DeepCGH: `4 цели → U-Net → фаза → 4 распространения → loss → backward` по весам сети, без фазовых меток. MSE — выбор команды; SSIM/объёмный cosine Zeng проверить отдельно.

Это предположение команды: цель не используется для усиления, абсолютная яркость между плоскостями не сохраняется. Проверить полутоновые цели, включая максимум ниже 1. Протокол организаторов имеет приоритет; при смене нормировки повторить оценку всех методов.

Подбор усиления по цели — только отдельный эксперимент с сохранёнными коэффициентами.

Фаза сохраняется по формуле `q = round(255 * (clip(phi, -π, π) + π) / (2π))`, читается как `phi_q = 2π*q/255 - π`. Реконструкции сохраняются как `round(255*clip(R_norm, 0, 1))`. Все PNG — режим `L`, без палитры и RGB.

Финальная проверка: **сохранить phase.png → прочитать → распространить поле → сохранить recon_1..4.png → прочитать → посчитать метрики относительно входных PNG**. Дополнительные float-метрики подписывать отдельно.

## 6. Данные и оценка обобщения

Пример — `[4, 128, 128]`, без эталонной фазы. По мотивам Yan 2025 использовать обычные 2D-цели; четыре выбирать независимо, без обязательной виртуальной глубины/RGB-D. Train генерировать на лету: точки, диски, линии, символы, затем полутоновые узоры и текстуры. EMNIST/Quick, Draw!/DIV2K — при наличии времени; загрузки не блокируют первый запуск.

Размеры ниже — рабочее решение команды, не требование задания:

| Набор | Размер | Назначение |
|---|---|---|
| Train | Поток; считать число показанных четвёрок | Обновление весов |
| Validation | 64 фиксированные четвёрки | Выбор checkpoint и изменений |
| Test | 64 другие фиксированные четвёрки | Финальная оценка после выбора модели |
| OOD | 16 фиксированных четвёрок | Новые формы, шрифты или частотные структуры |
| Examples | 4–8 заранее выбранных четвёрок | Наглядная демонстрация; не замена test |

В validation/test — по 16 четвёрок геометрии, символов, полутоновых и смешанных целей. Фотографии добавлять отдельной категорией. Четыре цели выбирать независимо.

- Разделять исходники до аугментаций и комбинаций; у генератора разделять RNG, для OOD удерживать новые формы/параметры.
- Seed train/val/test/OOD: `42/42001/42002/42003`. Проверять также отсутствие общих исходников.
- Manifest: ID, split, seed, исходники, генерация, порядок z, хеши PNG. Наборы не менять между сравнениями.
- Test использовать после выбора модели. Набор, использованный для подбора, становится validation.
- Пустые/постоянные цели — отдельная диагностика: их Pearson не определён.

Pearson — по всем пикселям. При нулевой дисперсии записать `null` и причину, показать число валидных пар/ошибок. Постоянная реконструкция непостоянной цели — провал случая, его нельзя незаметно исключать из отчёта.

SSIM: прочитанные PNG / 255, `data_range=1.0`, `win_size=7`; фиксировать остальные параметры и версию библиотеки. Отчёт: пары, категории, среднее по набору и худшее среднее среди плоскостей.

## 8. Обязательные эксперименты и проверки

Запуски сохранять с конфигурацией и метриками. За эксперимент менять один компонент.

1. **E0 — физика и устройство, A/B.** Прямое суммирование Френеля на маленькой сетке; мощность без crop: `sum(abs(Uz)**2)*dx_out**2 ≈ sum(abs(U0)**2)*dx_in**2`; конечность, влияние z, autograd конечными разностями. Учитывать глобальную фазу. Начальные относительные допуски: поле/мощность complex64 `1e-4`, градиент `1e-2`. B проверяет полный FFT/backward train-step на рабочем CPU/GPU и измеряет скорость.
2. **E1 — оптимизация фазы, A.** Одна/четыре плоскости, 100–300 шагов, до трёх стартов. Результат — диагностический ориентир, не глобальный оптимум.
3. **E2 — переобучение, B.** На 1–4 четвёрках. Без улучшения проверить градиенты, нормировку, выход, физику. Другую параметризацию фазы проверять отдельно.
4. **E3 — обобщение, B/C.** Adam `lr=1e-3`, batch 4–8, равные веса плоскостей. Сначала 300–500 шагов; при улучшении validation — 1 000–2 000 или измеренный бюджет. Сохранить начальную сеть, число показов и время шага.
5. **E4 — сравнение, A/C.** Обязательно: начальная сеть, обученная сеть, Adam по фазе на одинаковых целях. Опционально: сеть + 50 шагов Adam и случайная фаза + 50 шагов для проверки пользы инициализации. Это уточнение при инференсе; обучаемые итерации и фазы учителя — отдельные методы.
6. **E5 — сдача, C.** Сравнить float-фазу и фазу после PNG, выполнить путь раздела 5. Проверить размеры, режим `L`, порядок z и повторяемость метрик. Измерить отдельно сеть, уточнение и полный конвейер; синхронизировать ускоритель, исключить прогрев/IO из времени forward.

После MVP: SSIM/объёмный cosine loss, баланс плоскостей, разнообразие данных; затем interleave/Fourier-блок Zeng или альтернативная FCN Yan 2024. Гибридное обучение по фазам учителя — отдельный эксперимент с учётом периодичности и неоднозначности решения.

- Четыре реконструкции получены из сохранённого PNG согласованным оператором.
- Метрики воспроизводятся по PNG; JSON без NaN/Infinity.
- Есть конфигурация, manifests, seed, версии, checkpoint и команда инференса.
- В финальном пути нет заглушек, ручной обработки реконструкций и подмены метрик.

Проверка качества:

- Checkpoint выбирать по validation: максимальный худший средний SSIM среди плоскостей; при равенстве — средний Pearson.
- Основные непостоянные цели имеют определённые метрики; вырожденные выходы отмечены как ошибки.
- Сравнить обучение с начальной сетью по SSIM/Pearson и каждой плоскости; не скрывать провалы средним.
- Baseline и опциональный гибрид используют тот же протокол; указаны объём, шаги, старты, время, устройство. Превосходство сети не обещается.
- Неподтверждённое качество честно указать при сдаче вместе с диагностикой.

## 11. Пять источников и ограничения MVP

До MVP исключить GAN/диффузию/трансформеры, RGB/4K, реальную установку, camera-in-the-loop, сложные шумы, многофреймовость, веб-интерфейс, перебор архитектур и тысячи эталонных фаз. При остановке обучения сохранять checkpoint и логи.

Для MVP углублённо читать №1, №2 и №4; №3 — для данных, №5 — после MVP. В README кратко указать заимствованные идеи и собственные адаптации.

| № | Источник | Применение и граница |
|---|---|---|
| **1** | **Zeng 2026**, [A Deep Learning Framework for Multi-Plane Computer-Generated Holography](https://doi.org/10.3390/photonics13030252) | B: U-Net, каналы глубины, объёмный loss. В статье есть предварительное обучение по фазам и линзовая Fourier-модель; здесь архитектурная адаптация и собственный Френель. |
| **2** | **Eybposh 2020**, [DeepCGH](https://doi.org/10.1364/OE.399624), [код](https://github.com/UNC-optics/DeepCGH) | B: обучение через качество восстановления без обязательных фазовых меток. TensorFlow-реализация — референс, не зависимость. |
| **3** | **Yan 2025**, [Generation of Multiple-Depth 3D Computer-Generated Holograms from 2D-Image-Datasets Trained CNN](https://doi.org/10.1002/advs.202408610) | C: разнообразие 2D-данных. ASM и виртуальную глубину адаптировать к четырём независимым целям. |
| **4** | **Peng 2020**, [Neural Holography with Camera-in-the-loop Training](https://doi.org/10.1145/3414685.3417802), [код](https://github.com/computational-imaging/neural-holography) | A: PyTorch и градиентные/GS baseline. `algorithms.py` — референс; ASM заменить одно-FFT Френелем. Аппаратная калибровка исключена. |
| **5** | **Yan 2024**, [Generating Multi-Depth 3D Holograms Using a Fully Convolutional Neural Network](https://doi.org/10.1002/advs.202308886) | B после MVP: альтернативная FCN. Моделирование 3D-сцен, окклюзий и forward–backward ASM в основной путь не входят. |

GS из Peng — дополнительный baseline после Adam; не добавлять его на критический путь. При переносе кода сохранить атрибуцию, лицензию и ревизию источника. Метрики, время, готовые веса и оптические операторы статей напрямую не переносить: ни одна работа не совпадает со всеми параметрами кейса.
