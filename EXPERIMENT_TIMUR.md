# TIMUR-FORWARD: обучение на достижимых изображениях

Ветка: `timur`. База: `85e1267` (основной MVP и его анализ).

## Постановка

Меняется генерация целей: сохранённая предсказанная phase.png → четыре реконструкции Френеля → четыре PNG. Модель по-прежнему получает четыре изображения и предсказывает одну фазу. Архитектура, амплитудный протокол, нормировка и физический loss сохранены; эталонная фаза служит проверке достижимости, не новому supervised loss.

96 уникальных масок исходного best.pt взяты из outputs/test (64), outputs/ood (16), outputs/examples (8) и outputs/comparison/final/network (8). Это маски одной обученной сети, не произвольные фазы. Исходный checkpoint SHA256: `55ad50208b7545c1ea3f14485148fba089e6817d08eebfec9589eb42cb54412c`.

До генерации изображений маски разделены на train/val/test = 64/16/16, seed=42. В каждой исходной категории 16/4/4 маски. Повторы фаз и исходных sample IDs удаляются до split; исходные маски не пересекаются между наборами. Категория означает происхождение маски, не визуальный класс полученной реконструкции. Аугментаций нет.

## Запуск

```bash
python -m src.forward_data
python -m src.train --steps 500 --batch-size 8 --seed 42 --device cpu --train-manifest data/forward/train/manifest.json --val-manifest data/forward/val/manifest.json --checkpoint-dir checkpoints/timur_forward --run-dir runs/timur_forward
python -m src.train --resume checkpoints/timur_forward/last.pt --steps 1500 --batch-size 8 --seed 42 --device cpu --ssim-weight 0.1 --train-manifest data/forward/train/manifest.json --val-manifest data/forward/val/manifest.json --checkpoint-dir checkpoints/timur_forward --run-dir runs/timur_forward
```

Обучение с нуля из seed 42, batch=8, Adam lr=1e-3, бюджет 2000 шагов / 16 000 показов. Первые 500 шагов — MSE, следующие 1500 — MSE+0.1*(1−SSIM). Отбор checkpoint только по новым 16 val: худший средний SSIM плоскостей, затем Pearson. Исходные checkpoints не перезаписываются.

Сравниваются на одинаковом новом test: исходный best.pt, новая сеть, ближайшая train-четвёрка с её фазой и исходная фаза test-маски (контроль достижимости). Все метрики — общий PNG roundtrip. Исторические метрики старого test приводятся отдельно: набор целей изменился, разность с ними не является чистым эффектом обучения.

Дополнительный контроль применимости: 64 новые произвольные четвёрки исходного генератора, seed=44002, `data/timur_control/arbitrary_test/manifest.json`. На них сравниваются исходная и новая модели после фиксации checkpoint; эти данные не используются для выбора. Так отделяется успех на достижимых изображениях от переноса на первоначальную задачу.

## Проверки и ограничения

- Тесты проверяют точное восстановление целей из исходной фазы, повторяемость генерации, отсутствие общих родителей/хешей между splits и повторяемость train-потока.
- CLI проверен на двух реальных train-step и продолжении из last.pt.
- Обобщение здесь проверяется только на 16 новых масках той же сети-генератора. Это пилот с одним seed; вывод на произвольные изображения по нему не делается.
- Выполнены все 2000 обновлений; test открыт после фиксации checkpoint на шаге 1800. Ни данные test, ни дополнительный контроль не использовались для выбора.

## Итог

Обучение завершено: 2000 шагов / 16 000 показов, CPU, seed=42. Из них выбран шаг **1800** (14 400 показов) по худшему среднему SSIM четырёх плоскостей validation. Начальные веса побайтно совпали с исходным initial.pt. Архитектура — PhaseUNet(16, interleave_factor=1), 488 145 параметров.

Checkpoint: `checkpoints/timur_forward/best.pt`, SHA256 `4a16fcb91512efd57bcdbf2d85618e5a89aeec12ef0a3b85a519bf0abc10ad34`.

### Одинаковый отложенный forward-test: 16 масок / 64 пары

| Метод | Pearson | SSIM | Худший средний SSIM плоскости |
|---|---:|---:|---:|
| Исходная сеть без переобучения | 0.71949 | 0.85358 | 0.84306 |
| Сеть после forward-обучения | 0.98254 | 0.97127 | 0.96878 |
| Ближайшая train-четвёрка → её фаза | 0.34401 | 0.72330 | 0.69442 |
| Известная исходная test-фаза (контроль) | 1.00000 | 1.00000 | 1.00000 |

Обе метрики улучшились на всех 16 test-четвёрках. Парное изменение среднего SSIM **+0.11769**, Pearson **+0.26304**. Bootstrap по целым четвёркам (10 000 выборок, seed=42): 95% интервал изменения SSIM **[0.10566; 0.12962]**, Pearson **[0.22806; 0.29651]**. Это неопределённость выборки из 16 масок, не вариативность обучения по разным seeds. Ошибок нет; все 64 Pearson определены для каждого метода.

## Интерпретация

1. Прямая генерация гарантирует достижимость целей исходной фазой; контроль дал точно 1.0/1.0 по PNG.
2. Изменение самого набора уже повышает SSIM исходной сети до 0.85358 без переобучения. Исторические 0.11864 из RESULTS.md относятся к другим целям; разность с 0.97127 не является эффектом одного только обучения.
3. На этом же новом test переобучение добавило 0.11769 SSIM и 0.26304 Pearson; результат выше простого поиска ближайшей train-маски.
4. Четыре цели теперь согласованы одной фазой и статистически связаны. Семейство ограничено 96 масками старой сети; train содержит 64 уникальные четвёрки, повторённые за 250 эпох. Раньше train был потоком разных произвольных целей. Вклад достижимости, спектрального состава, корреляции плоскостей и размера семейства этим опытом отдельно не разделяется.
5. Сеть хорошо воспроизводит реконструкции старых масок. Точность восстановления исходных надписей/фигур этим результатом не подтверждается: они больше не являются целями данного forward-набора. Свежий произвольный контроль показывает ограниченный перенос.

## Воспроизведение оценки

```bash
python -m runs.timur_forward.evaluate
```

Данные и модели уже включены в ветку. Для обучения с нуля используются команды выше; временные каталоги исходного MVP не нужны. Дополнительный произвольный контроль восстанавливается вызовом `prepare_split(Path('data/timur_control'), 'arbitrary_test', 64, seed=44002)` из src.data.

Локальные проверки: **52 passed, 1 skipped** (Metal недоступен). Генерация всех 96 масок повторена в другом каталоге: manifests совпали. Перезагруженный best.pt точно воспроизвёл validation. Все **192** оценённых случая независимо восстановлены из phase.png; recon PNG и метрики совпали. Повторная оценка дала те же 960 рабочих PNG, 5 рисунков и 192 набора метрик. Исходный best.pt сохранил прежний SHA256. Время и Git-метаданные повторного запуска могут отличаться.
