# PIPELINE — хакатон «Нейросетевой синтез дифракционных оптических элементов»

**Команда:** 3 человека  
**Жёсткий предел:** 24 часа с начала хакатона  
**Плановое время до готового MVP:** 7–9 часов по календарю  
**Ориентир по активной работе:** 4–6 часов на человека; остальное — автоматическое обучение, проверки, отдых и запас  
**Подход:** один простой работающий конвейер, воспроизводимый результат, минимальное число зависимостей.

> **Цель:** по четырём одноканальным изображениям 128×128 за один проход нейросети получить **одну фазовую маску 128×128**, восстановить из неё четыре изображения на заданных расстояниях, сохранить PNG и вычислить Pearson/SSIM. Классическая оптимизация используется для проверки и сравнения, но **не заменяет нейросетевой метод**.

## 1. Общая схема решения

```text
4 входных PNG (grayscale, 128x128)
             │
             ▼
   чтение / масштабирование [0, 1]
             │
             ▼
      небольшая U-Net
       4 канала -> 1
             │
             ▼
   phi: 128x128, [-π, π]
             │
       U0 = exp(i*phi)
             │
        ┌────┼────┬────┐
        ▼    ▼    ▼    ▼
     Fresnel (один FFT на каждое z)
        │    │    │    │
        ▼    ▼    ▼    ▼
     |U1| |U2| |U3| |U4|
        │    │    │    │
        └────┼────┴────┘
             ▼
   loss при обучении / метрики при оценке
             │
             ▼
  phase.png + recon_1..4.png + metrics.json
```

### Базовый принцип обучения

1. Сеть принимает тензор `[B, 4, 128, 128]` и выдаёт фазу `[B, 1, 128, 128]`.
2. Формируем комплексное поле `U0 = exp(1j * phi)`.
3. Для каждого `z` вычисляем распространение **тем же одно-FFT оператором Френеля**, что используется при финальной проверке.
4. Берём модуль `A_k = abs(U_zk)`.
5. Согласованно нормируем `A_k` с целью `T_k`; считаем ошибку по всем 4 плоскостям:

   `loss = mean_k( MSE(normalize(A_k), T_k) )`.

6. Автоматическое дифференцирование PyTorch обновляет веса нейросети через FFT. Это **physics-driven** обучение без предварительных «правильных фаз».

**Для MVP не нужны:** GAN, диффузионные модели, трансформеры, огромные датасеты, 3D-моделирование объектов, реальная лазерная установка, сложные интерфейсы и многофреймовая голография.

## 5. Физические и вычислительные проверки — сделать обязательно

### 5.1. Формула Френеля из задания

Использовать одно-FFT форму интеграла Френеля (с точностью до принятой ориентации координат и FFT):

\[
U_z(x,y)=\frac{e^{ikz}}{i\lambda z}\,
 e^{\frac{i\pi(x^2+y^2)}{\lambda z}}
 \mathcal F\!\left[U_0(u,v)
 e^{\frac{i\pi(u^2+v^2)}{\lambda z}}\right].
\]

В дискретном FFT учитывать множитель площади входного пикселя `dx²`, согласованные `fftshift / ifftshift` и координаты **в метрах**. Глобальная фаза не влияет на модуль, но должна быть физически правильно обработана, если сохраняется комплексное поле.

### 5.2. Особенность одного FFT: выходная сетка зависит от расстояния

Для сетки `N=128`, входного шага `dx=10 мкм`:

\[
\Delta x_{out}(z)=\frac{\lambda z}{N\,\Delta x_{in}}.
\]

Ориентировочно: при 24,1 мм — **10,02 мкм**, при 27,7 мм — **11,51 мкм**.

Все четыре массива будут размером **128×128**, но их **физический масштаб разный**. Зафиксировать рабочее соглашение: целевые PNG сравниваются с массивами на соответствующей собственной сетке каждой плоскости. Не подменять одно-FFT модель угловым спектром или произвольным ресайзом без явной причины. При возможности уточнить у организаторов, требуется ли одинаковый физический размер всех изображений.

### 5.3. Нормировка и метрики

- `input_png`: `uint8` → `float32 / 255`.
- `phase_png`: `uint8 = round(255*(phi + π)/(2π))`, перед сохранением фаза ограничивается `[-π, π]`.
- Для **финальной проверки** читать **сохранённый** `phase.png` обратно в радианы, затем заново считать 4 реконструкции: так проверяется реальная 8-битная квантованная голограмма, а не только исходный float32-тензор.
- Для амплитуды `abs(U)` необходима **одна документированная схема приведения яркости** к `[0,1]` (например, оптимальный неотрицательный линейный коэффициент усиления для каждой плоскости, после чего clip). Физическая мощность освещения в условии не задана, поэтому эта нормировка — **наше предположение**, а не требование организаторов.
- Одну и ту же нормировку применять в обучении, к классическому методу и к итоговой оценке. Не менять метод нормировки ради «красивых» метрик.
- Сохранять Pearson и SSIM **для каждой из четырёх пар**, их среднее и минимум по четырём плоскостям. SSIM считать с фиксированным `data_range=1.0` на нормированных float-массивах, либо с `data_range=255` на PNG — последовательно и без смешения.
- Для Pearson на полностью постоянной картинке нужна явная обработка нулевой дисперсии; лучше не использовать пустые изображения в основных тестах.

### 5.4. Минимальные тесты перед обучением

- [ ] `z`, `λ`, `dx` заданы **в метрах**; ни один шаг FFT не трактует пиксели как метры.
- [ ] `fresnel_1fft(phi, z)` возвращает правильный размер и тип, значения конечны.
- [ ] Изменение `z` меняет восстановленную картину.
- [ ] `loss.backward()` даёт конечный ненулевой градиент по `phi` и параметрам модели.
- [ ] На одиночном наборе **прямая оптимизация фазы** действительно уменьшает ошибку за 20–50 шагов.
- [ ] Квантование в 8 бит и повторное чтение `phase.png` не ломают восстановление.
- [ ] Все 4 метрики Pearson и 4 SSIM считаются без исключений.

**Управление риском:** если физический оператор не проходит эти тесты, остановить улучшение архитектуры и чинить физику. Не обучать сеть на неправильной модели.

## 6. Минимальная стратегия обучения

**MVP, не научная публикация.** Начать с самого дешёвого эксперимента.

1. Вход: **четыре канала** изображений 128×128.
2. Небольшая U-Net без сложных блоков; начальная ширина **16** каналов. При наличии мощного GPU можно 32.
3. Генератор изображений работает **на лету**: случайные диски, линии, цифры, простые контуры, 1–5 фигур на картинку. Периодически менять положение, масштаб и яркость. Для тестов использовать **отдельные** изображения и конфигурации.
4. Оптимизатор **Adam**, начальная скорость обучения `1e-3`, batch size `4–8` как отправная точка; уменьшать batch size при нехватке памяти.
5. Loss для первой версии: среднее `MSE` по четырём восстановленным **модулям**. При необходимости добавить веса плоскостей, чтобы сеть не улучшала одни изображения за счёт других.
6. **Сначала 300–500 шагов.** Проверить: уменьшается ли loss, узнаваемы ли картинки, улучшаются ли Pearson/SSIM на отложенных примерах.
7. Если да — продолжить до **1 000–2 000 шагов** в рамках тайм-бокса. Не обещать заранее качество: оно зависит от оборудования, состава данных и сложности многоплоскостной задачи.
8. Сохранять лучший checkpoint, лог loss и изображения фиксированного validation-набора. `seed=42` для воспроизводимости.

**Опционально и только после MVP:** дообучение с `loss = MSE + α*(1-SSIM)` или дополнительный штраф за межплоскостные помехи. Это улучшение может усложнить обратное распространение; сначала получить устойчивую MSE-версию.

**Не нужно** генерировать 100 000 примеров и обучаться 40 часов по протоколу статьи 2018 года: он относится к иной задаче и иной методике обучения.

## 7. Классическая базовая линия и план B

### Базовая линия — обязательно, но ограничить трудозатраты

Оптимизировать **не веса сети, а саму фазу** для одной фиксированной четвёрки:

```text
случайная phi -> Fresnel на 4 расстояниях -> MSE
    -> Adam шаг по phi -> повторить 100–300 раз
```

Это быстрый способ доказать, что оператор распространения работает и что можно получить хотя бы приближённое решение. Сравнить исходную нейросеть, эту прямую оптимизацию и (опционально) гибрид.

### Если сеть обучилась слабо

**План B1 (предпочтительный):** использовать фазу, предсказанную сетью, как начальную точку для **20–100 шагов** оптимизации непосредственно фазы. Это всё ещё **гибридный нейросетевой метод**, но уже не одношаговое неитерационное решение. Обязательно показать отдельно качество и время **без уточнения** и **после уточнения**.

**План B2:** упростить обучающие примеры до разреженных контуров/точек, уменьшить ширину сети или batch size, выполнить короткое дополнительное обучение. Не менять несколько компонентов одновременно.

**Если нейросеть совсем не работает:** всё равно сохранить её код, checkpoint, выходы и честные метрики, а классический baseline представить **как ориентир**, не выдавая за требуемый нейросетевой алгоритм. Исправление критических ошибок важнее сомнительных «улучшений».

## 8. Жёсткие критерии готовности и отсечения задач

### Минимальный результат для сдачи — MUST HAVE

- [ ] Программа принимает **произвольные четыре** корректных PNG заданного размера.
- [ ] **Обученная нейросеть** генерирует одну фазовую маску 128×128.
- [ ] Маска сохраняется как 8-битный одноканальный `phase.png` с указанным диапазоном фаз.
- [ ] Из **этого сохранённого PNG** выполнено восстановление на всех четырёх заданных расстояниях **одним FFT Френеля**.
- [ ] Сохранены 4 одноканальных `recon_*.png`, также 128×128.
- [ ] Для каждой пары рассчитаны Pearson и SSIM, результаты сохранены в `metrics.json`.
- [ ] Есть команды установки/запуска, исходники, checkpoint и хотя бы один воспроизводимый пример.
- [ ] Нет NaN, битых PNG или ручного редактирования итоговых реконструкций.

### Хорошо иметь — SHOULD HAVE

- [ ] Классическая базовая линия для 1–2 тестовых четвёрок.
- [ ] Время генерации фазовой маски (отдельно от чтения PNG и физической проверки).
- [ ] Коллаж «четыре цели → одна фаза → четыре реконструкции».
- [ ] Таблица среднего и худшего по четырём плоскостям качества.
- [ ] Проверка чувствительности к 8-битному квантованию фазы.

### Не делать на этом хакатоне — CUT

- [ ] Обучение полноразмерного DeepCGH с нуля в чужой программной среде.
- [ ] Моделирование реальной оптической установки, шумов камеры, аберраций.
- [ ] Собственный веб-интерфейс/красивый сайт.
- [ ] Поиск «идеальной» архитектуры по десяткам экспериментов.
- [ ] RGB/4K, полная 3D-сцена, динамические голограммы, аппаратная демонстрация.

### Правила остановки

- **После 2 часов:** физический оператор должен работать; иначе всё внимание на него.
- **После 3 часов:** один сквозной запуск (возможно ещё со случайно инициализированной сетью).
- **После 5–6 часов:** зафиксировать рабочую версию checkpoint; никакого переписывания проекта.
- **После 7 часов:** только измерение, исправление серьёзных ошибок, документация и сдача.
- **После 9 часов:** если пакет уже корректен, **завершить работу**; остаток 24-часового лимита не нужно заполнять задачами.

## 9. Финальная упаковка для экспертов

**Что должно получаться после одной команды:**

```text
outputs/submission/
  phase.png
  recon_1.png
  recon_2.png
  recon_3.png
  recon_4.png
  metrics.json
  comparison.png     # полезно для презентации
```

В `metrics.json` записать настройки и метрики каждого из четырёх восстановлений, например:

```json
{
  "wavelength_m": 5.32e-7,
  "slm_pitch_m": 1.0e-5,
  "distances_m": [0.0241, 0.0253, 0.0265, 0.0277],
  "propagation": "single_fft_fresnel",
  "reconstruction_value": "abs(complex_field)",
  "phase_png_quantized": true,
  "normalization": "DOCUMENT_EXACT_RULE_IN_README",
  "per_plane": [
    {"z_m": 0.0241, "pearson": null, "ssim": null},
    {"z_m": 0.0253, "pearson": null, "ssim": null},
    {"z_m": 0.0265, "pearson": null, "ssim": null},
    {"z_m": 0.0277, "pearson": null, "ssim": null}
  ]
}
```

`null` — только шаблон; **перед сдачей там должны быть реальные числа**. Дописать среднее, минимум, версию checkpoint, seed, время инференса и при наличии — результат прямой оптимизации.

**README (максимум 1–2 страницы):** постановка → принцип `NN + Fresnel` → установка → одна команда запуска → схема нормировки → результаты → ограничения. Не тратить время на длинную теоретическую статью.

## 10. Две статьи для референса

**[1] Horisaki, R., Takagi, R., Tanida, J. (2018).** *Deep-learning-generated holography.* Applied Optics, 57(14), 3859–3863.  
https://doi.org/10.1364/AO.57.003859  
**Зачем читать:** идея нейросети, непосредственно вычисляющей фазовую голограмму. **Не копировать полностью:** там одна целевая плоскость и обучение на парах «интенсивность — фаза»; наш хакатон требует четыре плоскости.

**[2] Eybposh, M. H., et al. (2020).** *DeepCGH: 3D computer-generated holography using deep learning.* Optics Express, 28(18), 26636–26650.  
https://doi.org/10.1364/OE.399624  
**Зачем читать:** наиболее близкая идея многоплоскостной голографии и обучения через физическую модель без эталонных фаз. **Не переносить репозиторий целиком:** достаточно принципа из статьи.

Код DeepCGH для понимания подхода (TensorFlow; **не обязательная зависимость** проекта): https://github.com/UNC-optics/DeepCGH

## 11. Резюме для команды — решение за 30 секунд

1. **A** строит и проверяет одно-FFT физику; **B** делает маленькую U-Net; **C** — данные, PNG, метрики и классическую проверку.
2. **Через 2 часа** объединяем модули; **с 3-го часа** уже обучаем, а не продолжаем проектировать.
3. В обучении используем **сходство четырёх восстановленных модулей** с четырьмя исходными изображениями.
4. В финале проверяем качество по **8-битной сохранённой голограмме**, а не только по float-тензору.
5. **Цель — закончить за 7–9 часов**; 24 часа — исключительно запас, без лишних расширений.

**Критерий успеха:** программно воспроизводимый результат по требованиям организаторов, где нейросеть действительно участвует в генерации единой фазовой маски, а честная проверка её восстановления производится указанным методом Френеля.
