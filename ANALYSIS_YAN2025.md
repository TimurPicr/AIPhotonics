# Почему MVP не достигает метрик Yan 2025

Основной вывод: проект реализует существенно другой обратный оператор и протокол оценки; одновременно у текущего предсказателя есть измеримые проблемы качества. Увеличение бюджета обучения само по себе не устраняет эти причины.

Источник сравнения: [Yan et al., Advanced Science 2025, DOI 10.1002/advs.202408610](https://pmc.ncbi.nlm.nih.gov/articles/PMC11848602/), особенно §2.1–2.3 и §6. Заявленный SSIM 0.836 относится к другому входу/объекту оценки. Для численного воспроизведения нужна отдельная репликация метода и его оценщика.

В нашем AGENTS.md Yan выбран как источник идей данных; текущие сеть, физика и loss — самостоятельная адаптация. Результат MVP не является воспроизведением статьи.

## Что проверено локально

Checkpoint не изменялся: SHA256 `55ad50208b7545c1ea3f14485148fba089e6817d08eebfec9589eb42cb54412c`.
Новые эксперименты используют только фиксированные 64 validation-четвёрки; test/OOD и их опубликованные оценки не изменены.

Артефакты: [диагностика](runs/quality_diagnosis/summary.json), [оптимизация](runs/quality_diagnosis/optimization.json), [скрипт](runs/quality_diagnosis/diagnose.py).
Новые числа ниже — float-метрики; они явно отделены от официального PNG-протокола в RESULTS.md.

### 1. Подтверждён перекос категорий train/validation

`make_train_loader` выбирает тип изображения независимо для каждой плоскости. Эффективная вероятность geometry/symbols/grayscale равна 1/3: категория mixed дополнительно выбирает один из трёх типов. Поэтому вероятность четырёх одинаковых типов равна `3*(1/3)^4 = 1/27`.

В фиксированной validation три из четырёх категорий намеренно содержат однородные четвёрки.

| Проверка | Четвёрки одной категории | Всего | Доля |
|---|---:|---:|---:|
| Train, первые 1024, seed 42 | 35 | 1024 | 3.42% |
| Validation, восстановлены типы по source seeds | 50 | 64 | 78.13% |

Это дефект генератора C: распределение типов четвёрок не согласовано с validation/test. Сам по себе подсчёт ещё не измеряет вклад дефекта в итоговый SSIM; нужна контролируемая абляция с переобучением.

Исправление: семплировать тип четвёрки с теми же долями, что в заданном распределении оценки; внутри типа независимо генерировать четыре изображения. Обязательно сохранить разнообразные смешанные четвёрки. Существующие manifests не менять для парного validation-сравнения.

### 2. Слабое разделение плоскостей и большой фон

На 64 val:

- Средняя корреляция реконструкций разных плоскостей: **0.6291**, целей: **0.0487**.
- В geometry/symbols активная область `T > 0.05` занимает **3.81%** пикселей. Средняя доля энергии `R²` в ней — **6.21%**; вне неё — **93.79%**.
- Средняя нормированная амплитуда: фон **0.1304**, целевые пиксели **0.1550**. Контраст слабый.
- При подстановке реконструкции другого примера той же категории Pearson падает с **0.1670** до **0.0356**. Сеть использует вход; полного коллапса в одну маску нет.

Гипотеза по механизму: общий фон/дифракционные детали существенно сильнее полезной структуры, а разделение информации по z недостаточно. Эти наблюдения не доказывают физическую недостижимость целей и не задают потолок качества.

### 3. Нормировка и разреженность существенно меняют задачу loss

Нормировка `R/max(R)` жёстко устанавливает пик максимума в 1, хотя генератор часто создаёт цели с меньшим максимумом. Производная зависит от самого яркого пикселя; увеличение пика уменьшает остальные нормированные значения. Это создаёт нежелательный путь уменьшения ошибки фона без восстановления целевой структуры.

Диагностический подбор скалярного усиления по каждой цели уменьшает float MSE с **0.03152** до **0.01863**. Это свидетельство проблемы согласования яркости; коэффициент использует цель и не разрешает подменять им официальную оценку.

| Неизменная фаза, вариант диагностики | Pearson val | SSIM val |
|---|---:|---:|
| Текущая нормированная амплитуда | 0.16705 | 0.12616 |
| Её квадрат | 0.13455 | 0.23219 |
| Нулевые изображения | не определён | 0.59125 |

Нулевые изображения не являются валидным оптическим решением. Их SSIM показывает, как сильно в этой смеси разреженных данных оценка зависит от фона: для geometry нулевой SSIM=0.8740, symbols=0.9219. Следовательно, высокий SSIM без проверки сигнала/контраста/Pearson ещё не подтверждает качество синтеза. Увеличение SSIM после возведения в квадрат также не доказывает улучшение модели.

Рабочий режим amplitude согласован между train/infer; доказанной ошибки согласования между ними нет. Семантику PNG как амплитуды либо интенсивности нужно уточнять по условию организаторов.

### 4. Квантование не объясняет разрыв

При той же float-реконструкции квантование фазы до PNG меняет средний SSIM с **0.126164** до **0.126129**, то есть примерно на **0.000035**. Итоговый PNG-протокол даёт около 0.126063. Это несопоставимо с наблюдаемым разрывом качества.

### 5. Длинный baseline отделяет обучение от физики

Две заранее указанные validation-четвёрки: val_0000 (geometry) и val_0002 (grayscale). Adam: 1000 шагов; случайные старты seed=42/43/44, lr=0.1, исходный амплитудный MSE. Это диагностические локальные оптимумы.

| Цель | Сеть, средний Pearson/SSIM четырёх плоскостей | Adam seed 42, четыре плоскости | Сеть + 1000 Adam |
|---|---|---|---|
| val_0000 | 0.09180 / 0.01247 | 0.41783 / 0.17396 | 0.37640 / 0.33893 |
| val_0002 | 0.37671 / 0.31923 | 0.56941 / 0.26793 | 0.54640 / 0.27060 |

У разных случайных стартов четырёхплоскостного Adam: Pearson 0.3975–0.4178 для geometry и 0.5694–0.5737 для grayscale. На этих примерах прибавка не исчезает при смене старта.

Если оптимизировать только первую плоскость, её Pearson достигает **0.97667 / 0.98889** соответственно; для grayscale её SSIM **0.91190**. Остальные плоскости в этом контроле не оптимизируются, поэтому их среднее нельзя сравнивать с четырёхплоскостной задачей.

Гибрид — отдельный итерационный метод, не одношаговая сеть. SSIM при уменьшении MSE может ухудшаться, как видно на grayscale. По двум примерам нельзя обещать такое же улучшение всему набору. Плохой четырёхплоскостной Adam на 100 шагах не был доказательством физического потолка.

## Что исправлять по приоритету

1. **Данные C:** согласовать смесь типов четвёрок train/val; увеличить разнообразие положения, шрифтов, размеров, частот и динамического диапазона. Принятие: улучшение по каждой категории и худшей плоскости на неизменной validation.
2. **Протокол A/C:** явно решить смысл входной яркости. Если требуется интенсивность, сравнивать интенсивность с T либо амплитуду с sqrt(T) в отдельных согласованных экспериментах. Официальную нормировку сохранять, пока её изменение не разрешено условием; эксперимент с target-fitted gain подписывать отдельно.
3. **Обратная задача B/A:** проверить физически структурированный вход — аналитическое обратное распространение на native сетках заданного одно-FFT Френеля, затем кодирование Re/Im либо коррекция начальной фазы. Альтернатива: координатные каналы и явная глобальная/Fourier-ветвь. Чистый свёрточный переход «сдвинутая цель → сдвинутая фаза» плохо соответствует преобразованию Фурье, где сдвиг цели реализуется фазовым наклоном. Это гипотеза архитектурного ограничения, нуждающаяся в абляции.
4. **Loss B:** отдельно нормированные ошибки foreground/background плюс структурный/корреляционный член; сохранить штраф за паразитную энергию во всех четырёх плоскостях. Средний MSE при активной области около 4% недостаточно отражает качество целевых объектов. Подбирать веса только на validation; проверять, что выросли контраст и Pearson, а не только SSIM пустого фона.
5. **Обучение B:** сначала добиться уверенного переобучения 1–4 четвёрок по структуре и каждой плоскости, затем расширять поток. Проверить снижение lr и curriculum 1→2→4 плоскости. Увеличивать бюджет после подтверждения полезных градиентов и улучшения validation. Нынешний бюджет сам по себе не доказывает, что единственная причина — мало шагов.
6. **Диагностика A:** расширить 1000–3000 шагов/несколько стартов на заранее выбранные val-цели и сравнивать одинаковые loss/нормировку/время. Это даст ориентир достижимости; не является доказательством глобального оптимума.

Первый короткий эксперимент — исправленная смесь train при неизменных физике, архитектуре, loss и бюджете. Второй — структурированный обратный оператор. Совместная смена всех компонентов не позволит выяснить причину улучшения.

Для репликации статьи нужен отдельный протокол/набор и оценщик, а для текущего кейса сохраняется обязательный одно-FFT Френель и оценка всех пикселей четырёх плоскостей. После дальнейшего подбора итоговое качество следует подтверждать на новом зафиксированном test/OOD.
